2. Check the rules before the agent starts

After you launch, the agent shops on its own. Watch the payment check on the right: every payment it tries stops there first.

How Leash decides

  1. Rules decide. Verified payee, exact listed price, budget, category, returns.
  2. The AI judge can only tighten. It blocks on its own only when it finds prompt injection.
  3. You approve escalations in PayPal, not in a button the agent could press.
